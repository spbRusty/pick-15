# Pick 15 — Яндекс Игры

Браузерная игра на TypeScript + Vite.

## Правила

- Игроки по очереди выбирают свободные числа от 1 до 9.
- Повторно выбрать число нельзя.
- Побеждает тот, кто первым соберёт три своих числа с суммой 15.
- Если числа закончились, фиксируется ничья.

## Запуск

```bash
npm install
npm run dev
```

Сборка для загрузки в Яндекс Игры:

```bash
npm run build
```

Готовый архив формируется из содержимого папки `dist`.

## Мультиплеер

Используется встроенный асинхронный мультиплеер Yandex Games SDK (`ysdk.multiplayer.sessions`). Игра ищет записанные партии соперников через `init()`, сохраняет выборы игрока через `commit()` и публикует завершённую сессию через `push()`.

**Это не одновременная игра двух подключённых пользователей.** Соперник воспроизводится по сохранённой последовательности ходов. Собственный сервер для такого режима не требуется.

Для настоящего live-мультиплеера с комнатами, приглашениями и синхронизацией ходов в реальном времени потребуется отдельный сервер матчмейкинга и WebSocket-обмен. Локально, вне платформы, доступен тренировочный режим.
